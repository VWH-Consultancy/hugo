# Welcome to Our New Website!

We're thrilled to announce the launch of our new side site! This site will showcase our news, articles, and posts, built with modern tools and a focus on performance.

## Built with Hugo and GitHub Pages

This site is built with [Hugo](https://gohugo.io) and hosted on [GitHub Pages](https://pages.github.com). Hugo’s simplicity and speed make it a great fit for a blog like this, while GitHub Pages handles deployment automatically whenever we update the content.

## Thanks to the Terminal Theme

We’re using the [Terminal theme](https://github.com/panr/hugo-theme-terminal) by **panr**. A huge thank you to panr for creating and maintaining this beautiful open‑source theme.

## What’s Next

This website will serve as a blog where we’ll share project updates, technical articles, and industry insights. We plan to regularly post about our work, lessons learned, and new technologies we’re exploring.

You can browse all posts using the **Posts** link in the navigation menu.

Feel free to explore the site and check out our [About](/about) page to learn more about what we do. If you have any feedback or questions, don’t hesitate to reach out.

_Stay tuned for more updates!_
